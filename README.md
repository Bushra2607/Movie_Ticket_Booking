# Movie Ticket Booking System 🎬

A web-based Movie Ticket Booking System developed using HTML, CSS, JavaScript, PHP, and MySQL. The system allows users to browse movies, select theatres and shows, choose seats, and book movie tickets online.

## Features

### User Features

- User registration and login
- Browse available movies
- View movie details
- Select theatre and show
- View available seats
- Select preferred seats
- Booking summary
- Online ticket booking
- Payment page
- Ticket booking confirmation

### Admin Features

- Admin login
- Admin dashboard
- Manage movies
- Manage theatres
- Manage screens
- Manage shows
- Manage seats
- Manage users
- Manage bookings
- View ticket information

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
